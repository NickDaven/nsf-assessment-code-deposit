# Automatic Assessment Pipeline

This folder should contain the complete public-safe code and documentation for automatic rubric-based assessment.

## Required Contents

- Source code for automatic assessment and grading workflows.
- Data-processing and analysis scripts.
- Rubric-processing scripts or schema.
- Model/API configuration templates, with secrets removed.
- Reproducible experiment scripts.
- Output schema and result-file descriptions.
- Installation and run instructions.
- Validation and comparison procedures against human/instructor ratings.
- Documentation of public/restricted data boundaries.

Do not upload restricted student data, instructor ratings, identifiable records, credentials, API keys, tokens, or private IRB-controlled materials.
