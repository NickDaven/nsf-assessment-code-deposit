# NSF Assessment Code Deposit

This repository is a public-safe code deposit area for NSF-supported assessment-pipeline work.

Do not upload restricted student data, identifiable student information, grades, credentials, API keys, tokens, cloud keys, raw IRB-controlled materials, or private project records.

Each student folder contains project-specific subfolders. Each subfolder must include:

- Source code developed for the project.
- A clear README describing what the code does.
- Installation instructions for a new user.
- Run instructions with example commands.
- Input and output descriptions.
- Data provenance and privacy notes.
- Reproducibility notes, including environment, dependencies, random seeds, model names, and experiment IDs when applicable.
- A statement acknowledging NSF support. The exact NSF project number should be inserted after Dr. Zheng provides it.
