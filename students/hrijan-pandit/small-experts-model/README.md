# Small Experts Model

This folder should contain the complete public-safe code and documentation for small domain-aware/expert language model work.

## Required Contents

- Model training scripts.
- Domain adaptation scripts.
- Triplet or contrastive training scripts, if developed.
- Inference scripts.
- Configuration files.
- Experiment registry or exported experiment logs.
- Model/checkpoint inventory.
- Hyperparameters, random seeds, hardware/runtime notes, and model names.
- Installation and reproduction instructions.
- Public/restricted data boundary notes.

Do not upload restricted student-response data, private annotations, credentials, API keys, tokens, or cloud service keys.
